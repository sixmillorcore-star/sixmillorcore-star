# Sixmillor

**Developer tools · Windows apps · MCP integrations**

I build practical tools that make everyday work easier: Windows desktop apps, prompt workflows, and Model Context Protocol (MCP) integrations. My public projects focus on clear interfaces, local workflows, and useful documentation in English and Thai.

[Explore my repositories](https://github.com/sixmillorcore-star?tab=repositories) · [Skill Updater releases](https://github.com/sixmillorcore-star/skill-updater/releases/latest) · [Prompt Optimizer releases](https://github.com/sixmillorcore-star/prompt-optimizer/releases/latest)

## Featured projects

### [Skill Updater](https://github.com/sixmillorcore-star/skill-updater)
**Manage Codex and Claude Code skills from one Windows app.**

Discover installed skills, check supported update sources, and update eligible skills with local backups. Includes optional morning updates and an in-app release updater.

`C#` `PowerShell` `Windows Forms`

[Download Skill Updater](https://github.com/sixmillorcore-star/skill-updater/releases/latest) · [Read the documentation](https://github.com/sixmillorcore-star/skill-updater#readme) · [คู่มือภาษาไทย](https://github.com/sixmillorcore-star/skill-updater/blob/main/docs/README.th.md)

### [Prompt Optimizer](https://github.com/sixmillorcore-star/prompt-optimizer)
**Turn a rough request into a prompt you can review and reuse.**

Organize Thai and English requests into a goal, context, constraints, and expected output. Prompt processing uses local rules and templates, without an AI model or API key.

`C#` `Windows Forms` `Local text processing`

[Download Prompt Optimizer](https://github.com/sixmillorcore-star/prompt-optimizer/releases/latest) · [Read the documentation](https://github.com/sixmillorcore-star/prompt-optimizer#readme) · [คู่มือภาษาไทย](https://github.com/sixmillorcore-star/prompt-optimizer/blob/main/docs/README.th.md)

### [Discord Control MCP](https://github.com/sixmillorcore-star/discord-control-mcp)
**Connect MCP clients to the Discord bot API.**

A local Node.js MCP server with discoverable bot actions and an optional Gateway event bridge. Includes setup examples for Codex and Claude Code, plus security and validation documentation.

`JavaScript` `Node.js` `MCP` `Discord API`

[Explore Discord Control MCP](https://github.com/sixmillorcore-star/discord-control-mcp#readme) · [Setup guide](https://github.com/sixmillorcore-star/discord-control-mcp#install) · [คู่มือภาษาไทย](https://github.com/sixmillorcore-star/discord-control-mcp/blob/main/docs/README.th.md)

## How I build

- **Keep it practical.** Start with a task the tool can make easier.
- **Make behavior clear.** Explain what runs locally, what connects online, and what needs a review.
- **Document the details.** Include setup instructions, validation records, and known limits.
